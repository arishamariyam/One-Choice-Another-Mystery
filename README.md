# One Choice, Another Mystery

A Python-based interactive mystery game where every choice leads to a different path and mysterious ending.

## About the Project

One Choice, Another Mystery is a text-based interactive mystery game built with Python.

The player wakes up in a mysterious room and must choose between three different doors. Each door leads to a different story, unexpected events, choices, and multiple endings.

## Features

- Three different mystery paths
- Interactive player choices
- Branching storylines
- Multiple endings
- Input validation
- Suspenseful story elements

## Technologies Used

- Python
- Conditional statements
- User input
- Nested if/elif/else logic

## How to Play

1. Download or clone this repository.
2. Run `mystery_game.py` using Python.
3. Follow the instructions shown in the terminal.
4. Choose your path carefully.

## Future Plans

The Python version is the foundation of the project.

A future version will transform the game into an interactive web experience with a graphical interface, buttons, and a more immersive mystery environment.
